# 리베르 AI 영상제작센터 - 고객용 배포

이 저장소는 고객용 설치 파일과 자동 업데이트 정보만 제공합니다.
프로그램의 원본 소스 코드는 포함하지 않습니다.

## 설치 방법

1. 오른쪽의 **Releases**에서 최신 버전을 엽니다.
2. `LiberVideoCenter-Setup.exe`를 내려받아 실행합니다.
3. 설치 중 **바탕화면 바로가기 만들기**를 선택할 수 있습니다.

## 업데이트

프로그램을 열면 새 버전을 확인합니다. 업데이트 안내가 나오면 **업데이트**를 선택하면 됩니다.
